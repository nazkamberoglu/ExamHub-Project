# ExamHub Project
ExamHub is a user-based online exam system developed with ASP.NET. The project includes an admin panel and allows users to take exams based on selected courses.

Description

In this system, users can log in and participate in exams related to specific courses. Once an exam is completed, the score is automatically calculated, stored in the database, and the results are visualized with charts to track performance over time.

Admins can manage exams, courses, and users through a dedicated admin panel.

Features

User authentication and authorization

Admin panel for managing users, courses, and exams

Course-based exam selection

Online exam participation

Automatic score calculation after exam completion

Performance tracking with graphical reports

Exam results stored in the database
